# Archivos
### data.py - donde se guardan los datos de configuración
### helpers.py - pensado para métodos sin función de tests
### main.py - donde se realizan los tests
### pages.py - donde se almacenan los buscadores

## Algunas advertencias
### No mover nada a helpers ni a los buscadores

## Qué se tiene que configurar
### Es necesario cambiar el link de la página en data.py
### Es necesario que el link de la página contenga el '?lng=es'
### Cada test se ejecuta de manera individual
### Cada test está pensado para ser aprobado
